# 🌍 Sam Travel Agency Website (Frontend)

Frontend qismi **Next.js 13 App Router** va **TypeScript** yordamida qurilgan bo‘lib, O‘zbekistonning mashhur sayohat yo‘nalishlarini taqdim etadi.  
Sayt orqali foydalanuvchilar shaharlar haqida ma’lumot olishlari, turlarni ko‘rishlari, galereyalar bilan tanishishlari va agentlik bilan bog‘lanishlari mumkin.

---

## ✨ Features

- 🚀 **Next.js 13 (App Router)** + **TypeScript** asosida qurilgan.
- 📦 **Static export-ready** (`output: 'export'` bilan).
- 🗺️ Dinamik yo‘nalishlar (`[slug]` sahifalari).
- 🎯 Hero bo‘limlari, turlar, galereyalar va CTA komponentlari.
- 🌐 **Ko‘p tilli qo‘llab-quvvatlash** (`LanguageContext` orqali oddiy i18n).
- 🎨 **TailwindCSS** yordamida zamonaviy va moslashuvchan dizayn.
- 🖼️ **Lucide Icons** bilan UI elementlari.
